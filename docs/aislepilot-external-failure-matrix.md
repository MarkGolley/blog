# AislePilot external failure matrix

This matrix defines the degraded behaviour required when optional dependencies fail. The core meal plan must remain usable whenever the failed dependency is not itself the requested deliverable.

The shared `AssertValidCorePlan` regression contract requires the expected meal count, recognized meal slots, named meals, ingredient lines, recipe steps, usable fallback/generated image URLs, positive meal costs, shopping items, aisle order, and consistent budget delta/over-budget state. OpenAI, Firestore, image, layout, and dessert degradation tests all apply this contract.

| Dependency | Injected failure | Required behaviour | Automated proof |
| --- | --- | --- | --- |
| OpenAI meal generation | HTTP 429 across the bounded retry allowance | Return a compatible local recipe plan with the requested meal count | `BuildPlan_WhenAiReturnsRateLimit_FallsBackToTemplatePlan` |
| Firestore meal hydration | Unreachable Firestore endpoint | Return a local recipe plan without throwing or claiming generated meals | `BuildPlan_WhenFirestoreHydrationIsUnavailable_FallsBackWithoutThrowing` |
| Meal-image generation | Permanent HTTP 400 | Return no generated bytes, do not retry a permanent failure, and retain the existing fallback-image path | `TryGenerateMealImageBytesWithAiAsync_PermanentApiFailure_IsNotRetried`; `MealImages_WhenAiImageGenerationDisabled_ReturnsCanGenerateImagesFalse`; `BuildPlan_AssignsMealImageUrl_ForEveryMeal` |
| Supermarket layout research | Weak or unusable research payload | Reject the payload and retain the curated chain layout with review metadata | `ParseSupermarketLayoutResearchResponse_WithWeakEvidence_ReturnsNull`; `BuildPlan_Aldi_UsesCuratedDefaultLayoutMetadata_AndDoesNotPutBakerySecond` |
| Dessert generation/persistence | External work unavailable or deferred | Return the core plan immediately and use a compatible local dessert when requested | `BuildPlanAsync_WithInteractiveAiDisabled_IncludesDessertWithoutWaitingForExternalWork`; `TemplateFallback_DairyAllergen_ExcludesDairyFromMealsAndOptionalDessert` |
| PDF/text export formatter | Formatter throws unexpectedly after the plan is resolved | Return a controlled 500 Problem Details response, expose no exception detail, and leave the in-browser plan unaffected | `Export_WhenFormatterFails_ReturnsControlledProblemResponse` |

## Boundary

Exports are requested deliverables rather than optional plan inputs. A formatter failure therefore cannot produce the requested file; the safe contract is a retryable, non-leaking Problem Details response. OpenAI, Firestore, image generation, layout research, and dessert enrichment are optional to the core plan and must not prevent that plan from being returned.
